# Словарь текстов интерфейса «Медархив»

Канонический словарь всех подписей интерфейса и сообщений об ошибках. Из него генерируются `apps/web/lib/texts.ts` и каталог ошибок бэкенда; в коде строки интерфейса вне словаря запрещены (`AGENTS.md`, раздел 3). Каталог ошибок в разделе 16 совпадает с `MedArchive/01_common/06-api-contract.md`, раздел 8; при правке меняются оба файла.

Откуда текст, если источники расходятся: поля, статусы и коды из `openapi.yaml`; тексты ошибок из каталога `06-api-contract.md`, раздел 8; прочие подписи из `04-customer-journey.md`, а если он молчит, из макета `02_design/source/gen.py`.

Колонка «Статус»:

| Значение | Что значит |
|---|---|
| пакет: ... | Текст взят из пакета ТЗ без изменений, указан источник |
| решение плана | Текст или правило утверждены владельцем в плане «Медархив по блокам», блок 0 |
| **новый текст, требует утверждения владельцем** | В пакете текста нет, формулировка написана заново |

Подстановки в фигурных скобках: `{title}` название документа, `{q}` поисковый запрос, `{n}` число, `{date}` дата `дд.мм.гггг`, `{time}` время `чч:мм`, `{size}` размер по правилу раздела 2.

## 1. Правила оформления

| Правило | Как | Статус |
|---|---|---|
| Многоточие | Один символ `…` (U+2026), не три точки: «Сохраняем…» | решение плана |
| Кавычки | «ёлочки» вокруг названий документов и запросов: «Общий анализ крови», «рентген» | решение плана |
| Длинное тире | U+2014 запрещено во всех текстах (правило `REVIEW.md`) | пакет: REVIEW |
| Диапазон | Короткое тире U+2013 с пробелами: «01.04.2026 – 30.04.2026» | решение плана |
| Разделитель метаданных | Точка по центру U+00B7 с пробелами: «PDF · 79 КБ · Есть заметка» | пакет: D06 |
| Точка в конце | Заголовки, кнопки, подписи полей, чипы, тосты и сообщения каталога ошибок без точки в конце; поясняющие абзацы с точкой | **новый текст, требует утверждения владельцем** |
| Регистр | С заглавной только первое слово: «Сохранить в архив», «Сбросить всё» | пакет: макеты |
| Буква «ё» | Пишется всегда: «всё», «удалён», «введённые» | пакет: макеты |
| Число и единица | Между числом и единицей неразрывный пробел U+00A0: «79 КБ», «20 МБ» | **новый текст, требует утверждения владельцем** |

## 2. Числа, даты, склонения

| Что | Правило | Пример | Статус |
|---|---|---|---|
| Дата документа | `дд.мм.гггг`, моноширинный Medeo Mono | 08.04.2026 | решение плана |
| Момент загрузки | `дд.мм.гггг, чч:мм`, 24 часа, в зоне пользователя (`timezone` сессии), моноширинный | 10.11.2026, 19:02 | решение плана |
| Диапазон дат | `{from} – {to}` (U+2013); только начало: `с {from}`; только конец: `по {to}` | 01.04.2026 – 30.04.2026 | решение плана; вариант «по {to}» **новый текст, требует утверждения владельцем** |
| Размер до 999 КБ | `kb = round(bytes / 1000)`, округление половины вверх, не меньше 1: `{kb} КБ` | 79114 → 79 КБ | решение плана |
| Размер от 1000 КБ | `round(bytes / 1 000 000, 1)` с десятичной запятой, «,0» отбрасывается: `{mb} МБ` | 2 400 000 → 2,4 МБ; 20 000 000 → 20 МБ | решение плана |
| Лимит загрузки | 20 971 520 байт всегда пишется «20 МБ», как в каталоге ошибок | | пакет: каталог |
| Процент загрузки | Целое число без пробела перед знаком | 62% | пакет: D05 |
| Подпись экспорта | Размер берётся из `total_bytes` ответа `POST /api/v1/exports`, числа в макетах (157, 466) не используются | Скачать ZIP · 158 КБ | решение плана |

Склонение после числа `n`: форма «один», если `n % 10 = 1` и `n % 100 ≠ 11`; форма «несколько», если `n % 10` от 2 до 4 и `n % 100` не от 12 до 14; иначе форма «много». Статус: решение плана.

| Слово | Один | Несколько | Много | Где |
|---|---|---|---|---|
| документ | 1 документ, 21 документ | 2 документа, 22 документа | 5 документов, 11 документов | Список, экспорт, подсказка без даты |
| страница | 1 страница | 2 страницы | 5 страниц | Файл в форме добавления |
| найден | Найден 1 документ | Найдено 3 документа | Найдено 5 документов | Подпись над списком с фильтром |
| участвует | не участвует | не участвуют | не участвуют | Подсказка без даты |

Название по умолчанию из имени файла: без `.pdf`, без ведущих цифр, `-` и `_` заменяются пробелами, первая буква заглавная («01-general-blood-test.pdf» → «General blood test»). Статус: пакет: путь, 1.2; FE-12.
