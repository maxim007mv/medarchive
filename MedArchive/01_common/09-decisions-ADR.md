## ADR-001. Серверное хранение вместо хранения в браузере

- **Область:** Стек
- **Выбрано:** PostgreSQL + Object Storage на сервере
- **Где:** Все данные архива
- **Отброшено:** IndexedDB / OPFS в браузере
- **Почему:** Хранилище браузера best-effort: браузер вправе очистить его при нехватке места, а пользователь теряет архив при смене устройства; требование R7 «данные сохраняются» не выполняется гарантированно
- **Источник:** S12

## ADR-002. Бэкенд FastAPI на Python 3.12

- **Область:** Стек
- **Выбрано:** FastAPI + Pydantic 2 + SQLAlchemy 2 async
- **Где:** `api/`
- **Отброшено:** Go (chi), Node (NestJS), только Next.js Route Handlers
- **Почему:** OpenAPI 3.1 и JSON Schema генерируются из типов, валидация Pydantic, DI для сессий и скоупов, cookie-сессии из Starlette; Python даёт pypdf и SDK моделей для AI-подсказки. Go быстрее в CPU, но узкое место сеть и S3
- **Источник:** S50

## ADR-003. Фронтенд Next.js 15 App Router + TypeScript

- **Область:** Стек
- **Выбрано:** Next.js, SSR каркаса списка
- **Где:** `web/`
- **Отброшено:** Vite SPA, SvelteKit
- **Почему:** SSR даёт быстрый первый экран; `next/font/local` самохостит Medeo без внешних запросов и сдвига вёрстки
- **Источник:** S54

## ADR-004. Примитивы интерфейса Radix через shadcn/ui

- **Область:** Стек
- **Выбрано:** Radix Dialog, RadioGroup, Popover, Toast
- **Где:** Модалки, сегменты, меню
- **Отброшено:** Свои компоненты, MUI
- **Почему:** Фокус-ловушка, Esc, возврат фокуса на триггер и паттерн WAI-ARIA готовы; стили полностью наши
- **Источник:** S53

## ADR-005. Серверное состояние TanStack Query

- **Область:** Стек
- **Выбрано:** Кэш запросов, оптимистичное обновление заметки с откатом
- **Где:** `web/lib/api`
- **Отброшено:** Redux, SWR
- **Почему:** Снимок в onMutate и откат в onError из документации: заметка не теряется при ошибке
- **Источник:** S56

## ADR-006. Шрифт Medeo Sans и Medeo Mono

- **Область:** Стек
- **Выбрано:** Medeo 1.1.0, OFL 1.1
- **Где:** Весь интерфейс, даты и ключ моноширинным
- **Отброшено:** Inter, системный шрифт
- **Почему:** Открытая лицензия, полная кириллица, вариативная ось веса, моно-начертание для дат; проверено встраиванием в PDF брендбука
- **Источник:** S15

## ADR-007. Хостинг только Yandex Cloud ru-central1

- **Область:** Инфраструктура
- **Выбрано:** Managed PostgreSQL, Object Storage, KMS, Lockbox
- **Где:** Онлайн-среда
- **Отброшено:** Vercel, Fly.io, Neon, Supabase
- **Почему:** Медицинские данные это специальная категория ПДн; хранение ПДн граждан РФ в базах на территории РФ
- **Источник:** S41, S42

## ADR-008. Уровень защищённости проектируем как УЗ-2

- **Область:** Безопасность
- **Выбрано:** Меры для специальной категории при угрозах 3 типа и больше 100 тыс. субъектов
- **Где:** Все меры 08-security
- **Отброшено:** УЗ-3 (меньше 100 тыс. субъектов)
- **Почему:** Рост пользователей не должен требовать переделки архитектуры
- **Источник:** S43

## ADR-009. Сессия BFF в cookie вместо JWT в браузере

- **Область:** Безопасность
- **Выбрано:** `__Host-ma_sid`, HttpOnly, Secure, SameSite=Lax, хэш в БД
- **Где:** Веб-клиент
- **Отброшено:** JWT в localStorage, JWT + refresh в браузере
- **Почему:** Токен недоступен XSS, отзыв мгновенный; BFF рекомендован черновиком IETF для браузерных приложений
- **Источник:** S28, S30, S31

## ADR-010. Ключ доступа вместо регистрации

- **Область:** Безопасность
- **Выбрано:** 24 символа Crockford Base32, секрет Argon2id m=19 MiB t=2 p=1
- **Где:** Восстановление архива на другом устройстве
- **Отброшено:** Email + пароль, magic link
- **Почему:** Нет лишних ПДн (email) и внешней рассылки; параметры Argon2id по минимуму OWASP
- **Источник:** S51

## ADR-011. Envelope-шифрование на уровне приложения

- **Область:** Безопасность
- **Выбрано:** DEK на пространство (Tink), обёрнут KEK в Yandex KMS; поля AES-256-GCM с AAD = document_id; файлы Tink Streaming AEAD
- **Где:** Название, заметка, имя файла, PDF
- **Отброшено:** Только шифрование диска провайдером, pgcrypto
- **Почему:** Дамп, бэкап или реплика без KMS не раскрывают данные; pgcrypto передаёт ключ в SQL и журналы; AAD не даёт перенести шифртекст между записями
- **Источник:** S35, S44, S52

## ADR-012. Криптоудаление при удалении архива

- **Область:** Безопасность
- **Выбрано:** Удаление DEK пространства в KMS + физическая очистка за 24 ч
- **Где:** `DELETE /workspace`
- **Отброшено:** Только удаление строк
- **Почему:** Копии в бэкапах PITR 7 дней становятся нерасшифровываемыми сразу
- **Источник:** S44, S48

## ADR-013. Изоляция RLS в БД дополнительно к проверкам в коде

- **Область:** Безопасность
- **Выбрано:** FORCE RLS, `app.workspace_id` через `set_config(..., true)`
- **Где:** Все таблицы данных
- **Отброшено:** Только `WHERE workspace_id` в репозитории
- **Почему:** Ошибка в одном запросе не открывает чужие данные (API1 BOLA); локальная настройка безопасна в пуле транзакций
- **Источник:** S27, S32

## ADR-014. PostgreSQL 17+ (проверено на 18)

- **Область:** БД
- **Выбрано:** Managed PostgreSQL 17, совместимо с 18
- **Где:** БД
- **Отброшено:** SQLite, MongoDB
- **Почему:** RLS, GIN, частичные индексы, PITR в управляемом сервисе
- **Источник:** S32, S33, S36

## ADR-015. UUIDv7 как первичный ключ

- **Область:** БД
- **Выбрано:** Генерация в приложении, на PG 18 `uuidv7()`
- **Где:** Все сущности
- **Отброшено:** bigint identity, UUIDv4
- **Почему:** Не раскрывает количество, не перебирается, монотонен по времени: меньше разрывов страниц btree, чем у v4
- **Источник:** S38

## ADR-016. Слепой триграммный индекс для поиска по зашифрованному названию

- **Область:** БД
- **Выбрано:** HMAC-SHA256 триграмм с ключом пространства, `bigint[]`, GIN
- **Где:** `documents.title_bidx`
- **Отброшено:** pg_trgm по открытому тексту, поиск после расшифровки всего архива
- **Почему:** Поиск по подстроке без открытого текста в БД; утечка ограничена частотами триграмм внутри одного пространства (документирована в 07-database)
- **Источник:** S33

## ADR-017. Keyset-пагинация по сгенерированному ключу

- **Область:** БД
- **Выбрано:** `list_key`, индекс `(workspace_id, list_key, uploaded_at, id)`
- **Где:** Список документов
- **Отброшено:** OFFSET, курсор по смешанным направлениям сортировки
- **Почему:** Стоимость O(page_size) на любой глубине; один направленный ключ даёт условие индекса без Sort
- **Источник:** S21, S39

## ADR-018. Мягкое удаление + очистка за 24 ч

- **Область:** БД
- **Выбрано:** `deleted_at`, ограничивающая политика `hide_deleted`
- **Где:** Документы, архивы
- **Отброшено:** Немедленное физическое удаление, корзина на 30 дней
- **Почему:** Атомарный быстрый ответ пользователю и гарантированное уничтожение по сроку; корзина противоречит ожиданию «удалено без возможности восстановления»
- **Источник:** S34, S48

## ADR-019. Журнал аудита только на добавление, по месяцам

- **Область:** БД
- **Выбрано:** `audit_log`, только имена изменённых полей
- **Где:** Все изменения
- **Отброшено:** Логи приложения
- **Почему:** Подотчётность (STRIDE Repudiation) без копирования ПДн в журнал
- **Источник:** S49, S55

## ADR-020. REST, версия в пути `/api/v1`

- **Область:** API
- **Выбрано:** Ресурсы во множественном числе
- **Где:** Все маршруты
- **Отброшено:** GraphQL, версия в заголовке
- **Почему:** Простое кэширование, логирование и контрактные тесты; версия видна в логах
- **Источник:** S23, S25, S26

## ADR-021. Ошибки RFC 9457 с каталогом кодов

- **Область:** API
- **Выбрано:** `application/problem+json`, `code`, `errors[].pointer`, `title` на русском
- **Где:** Все 4xx и 5xx
- **Отброшено:** Своя обёртка
- **Почему:** Стандарт, стабильный `code` для кода и готовый текст для интерфейса
- **Источник:** S16

## ADR-022. Idempotency-Key на создающих POST

- **Область:** API
- **Выбрано:** 24 часа, отпечаток тела, 400 / 422 / 409
- **Где:** Архив, загрузка, документ, экспорт, подсказка
- **Отброшено:** Без ключа, дедупликация по содержимому
- **Почему:** Двойной клик и повтор после обрыва не создают дубликат
- **Источник:** S19

## ADR-023. ETag / If-Match для изменения и удаления

- **Область:** API
- **Выбрано:** Версия строки, 428 без заголовка, 412 при конфликте
- **Где:** PATCH, DELETE
- **Отброшено:** Последняя запись побеждает
- **Почему:** Правка заметки в двух вкладках не теряет текст
- **Источник:** S17, S18, S24

## ADR-024. Курсорная пагинация, `order_by` по AIP-132

- **Область:** API
- **Выбрано:** Непрозрачный `page_token` AES-GCM, `page_size` до 200
- **Где:** `GET /documents`
- **Отброшено:** offset/limit
- **Почему:** Стабильно при вставках, токен нельзя подделать
- **Источник:** S21, S22

## ADR-025. Presigned POST для загрузки

- **Область:** API
- **Выбрано:** `content-length-range` 1 до 20 МБ, бакет карантина
- **Где:** `POST /uploads`
- **Отброшено:** Multipart через API
- **Почему:** API не держит 20 МБ в памяти, лимит проверяет хранилище
- **Источник:** S45, S47

## ADR-026. Лимиты с заголовками RateLimit и 429 + Retry-After

- **Область:** API
- **Выбрано:** GCRA в Redis
- **Где:** Все изменяющие маршруты, вход по ключу
- **Отброшено:** Без лимитов, лимит только на прокси
- **Почему:** Защита от перебора ключа и расхода ресурсов (API4), клиент знает, когда повторить
- **Источник:** S18, S20, S27

## ADR-027. Вебхуков нет в v1

- **Область:** API
- **Отброшено:** Вебхук «документ добавлен»
- **Почему:** Нет потребителей; каждый исходящий вызов это канал утечки и SSRF
- **Источник:** S27

## ADR-028. `Cache-Control: no-store` на ПДн

- **Область:** API
- **Где:** Все ответы с документами
- **Отброшено:** private, max-age
- **Почему:** Копия в кэше на общем компьютере это утечка
- **Источник:** S17, S28

## ADR-029. Модульный монолит + отдельный воркер

- **Область:** Архитектура
- **Выбрано:** `api` (модули documents, uploads, exports, auth, suggestions) + `worker` (arq)
- **Где:** Бэкенд
- **Отброшено:** Микросервисы
- **Почему:** Одна транзакция на создание документа; воркер только для AI и очистки
- **Источник:** S25

## ADR-030. Ограниченная очередь к модели с отказом 429

- **Область:** Архитектура
- **Выбрано:** 20 задач на инстанс, таймаут 8 с
- **Где:** AI-подсказка
- **Отброшено:** Неограниченная очередь, синхронный вызов без лимита
- **Почему:** Всплеск не превращается в таймауты у всех; основной сценарий не зависит от AI
- **Источник:** S18, S20

## ADR-031. AI только подсказывает и не сохраняет

- **Область:** Архитектура
- **Выбрано:** Подсказка помечена, дата с цитатой из PDF, сохраняет человек
- **Где:** Форма документа
- **Отброшено:** Автосохранение распознанного
- **Почему:** Задание не требует распознавания; ошибка модели не должна попасть в медицинский архив молча
- **Источник:** S7

## ADR-032. Нейтральная палитра, один бирюзовый акцент, чёрная главная кнопка

- **Область:** Дизайн
- **Выбрано:** Токены светлой и тёмной темы, 34 пары AA
- **Где:** Весь интерфейс
- **Отброшено:** Цветные главные кнопки, бежевые фоны
- **Почему:** Акцент сохраняет значение; контраст проверен по WCAG 2.2
- **Источник:** S9, S11

## ADR-033. Светлая тема по умолчанию + тёмная

- **Область:** Дизайн
- **Выбрано:** Системная настройка + переключатель
- **Где:** Весь интерфейс
- **Отброшено:** Только тёмная
- **Почему:** Светлая читается лучше большинством пользователей; тёмная по выбору
- **Источник:** S4

## ADR-034. Модалка только для необратимого и коротких форм

- **Область:** Дизайн
- **Выбрано:** Удаление, экспорт, форма документа
- **Где:** D10, D11, D13
- **Отброшено:** Модалка для просмотра документа
- **Почему:** Модалка прерывает работу; просмотр в боковой панели сохраняет контекст списка
- **Источник:** S1, S2

## ADR-035. Применённые фильтры чипами + «Сбросить всё»

- **Область:** Дизайн
- **Выбрано:** Чипы над таблицей, «3 из 6»
- **Где:** D06, D07
- **Отброшено:** Счётчик «Фильтры (2)»
- **Почему:** Пользователь видит, почему список короче
- **Источник:** S8

## ADR-036. Документ без даты явно помечен и не теряется в фильтре

- **Область:** Дизайн
- **Выбрано:** Метка «Не указана», в конце списка, подсказка «1 документ без даты не участвует... Показать его»
- **Где:** Список, фильтр по дате
- **Отброшено:** Пустая ячейка, исключение без сообщения
- **Почему:** Ничего не пропадает молча
- **Источник:** S3, S7

## ADR-037. Скелетон для ожидания 1 до 10 с

- **Область:** Дизайн
- **Выбрано:** Серый шиммер формы строк
- **Где:** Первая загрузка списка
- **Отброшено:** Спиннер на весь экран
- **Почему:** Скелетон снижает воспринимаемое ожидание и показывает структуру
- **Источник:** S5, S6

## ADR-038. Цели нажатия от 40 px, вся строка кликабельна

- **Область:** Дизайн
- **Выбрано:** Строки списка, радио-строки
- **Где:** Все интерактивные элементы
- **Отброшено:** Только иконка 16 px

- **Источник:** S10
