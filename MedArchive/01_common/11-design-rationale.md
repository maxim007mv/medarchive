# 11. Обоснование дизайна: экраны и действия

Для каждого экрана и действия клиента: что видит и делает пользователь, какое решение принято, что отброшено и почему. Номера экранов и снимки по `02_design/screens.md` (ADR-049), они же в Figma. Источники S.. в `02-research-sources.md`.

## 1. Экраны

| Экран | Решение | Отброшено | Почему | Источник |
|---|---|---|---|---|
| D01 / M01 Пустой архив и согласие | Объяснение в 3 пунктах, чекбокс согласия, одна кнопка «Выбрать первый PDF»; disabled с причиной до согласия | Пустая таблица с подписью «Нет данных»; регистрация | Пустое состояние должно учить следующему шагу; согласие обязательно до обработки сведений о здоровье | S3, S41 |
| D02 / M03 Форма нового документа | Модалка 560 (на мобильном лист): файл, название, тип сегментом, дата, «Дата не указана в документе» | Отдельная страница формы; выпадающий список типов | Короткая форма в контексте списка; 3 типа видны сразу одним кликом | S1, S8 |
| D03 Дата не указана | Чекбокс «Дата не указана в документе» блокирует поле даты и объясняет последствия для фильтра | Пустое поле даты без пояснения | Явное «неизвестно» вместо пустоты | S3 |
| D04 Ошибки файла и полей | Сообщение у файла: что случилось и что делать; ошибка под полем после попытки сохранить | Тост «Ошибка»; ошибка при первом фокусе | Ошибка рядом с причиной, конкретная и вежливая; не наказывать до попытки | S7 |
| D05 Обрыв загрузки | Процент, «Связь прервалась на 62%», введённые поля сохранены, «Повторить загрузку» | Сброс формы | Не заставлять вводить заново | S7 |
| D06 Список и поиск | Таблица: название, тип, дата документа, дата загрузки; поиск с «/»; «2 из 6»; чип запроса | Карточки на десктопе | Таблица сравнивает даты и типы взглядом | S8 |
| D07 Фильтр по периоду | Сегмент «Дата документа / Дата загрузки», два поля дат, «3 из 6», подсказка про документ без даты с «Показать его» | Молчаливое исключение | Пользователь не должен думать, что документ потерян | S3, S8 |
| D08 Ничего не найдено | Повтор условий; есть только запрос: «Сбросить поиск»; есть даты: «Убрать фильтр по дате» и «Сбросить всё» | «Нет результатов» | Пустой результат предлагает выход | S3 |
| D09 Документ и заметка | Боковая панель 420 рядом со списком: PDF, мета, заметка с автосохранением | Модалка, отдельная страница | Сохраняется контекст списка, удобно идти по документам подряд | S1 |
| D10 Редактирование описания | Та же панель переходит в форму с полями добавления: название, тип, дата | Отдельная страница редактирования | Одна форма для создания и правки, контекст списка сохраняется | S1 |
| D11 Удаление | Модалка «Удалить документ?» с названием и датой, «Отмена» в фокусе | «Вы уверены?», корзина | Подтверждение только для необратимого и конкретно | S2 |
| D12 Экспорт | Радио-строки «Только найденные · N» / «Весь архив · N», объём | Выпадающий список | 2 варианта с пояснением | S8 |
| D13 Скелетон | Повторяет форму строк | Спиннер | Структура видна | S5 |
| D14 Нет связи | Баннер, изменения заблокированы с причиной, «Повторить» | Ошибка на каждое действие | Одно понятное состояние | S7 |
| D15 / D16 AI-подсказка (вне объёма прототипа, ADR-042) | Бирюзовый шиммер в полях, метка «подсказка», цитата для даты | Автосохранение распознанного | Человек проверяет значения | S6, S7 |
| Тёмная тема (все экраны) | Те же роли цвета, поверхности светлее при подъёме | Инверсия | Иерархия глубины сохраняется | S4, S11 |
| M02 Список на мобильном | Карточки 14 px радиус, вся карточка кликабельна, нижняя кнопка «Добавить PDF» 48 px над безопасной зоной | Таблица с прокруткой | Ширина 390 не вмещает 4 колонки | S10, S13 |
| M04 Фильтр на мобильном | Нижний лист с «Показать 3» | Экран фильтров | Результат виден до применения | S8 |
| M07 Удаление на мобильном | Нижний лист, красная «Удалить» сверху, «Отмена» ниже, обе 48 px | Системный alert | Единый стиль и безопасная зона | S2, S10 |
| M08 Экспорт на мобильном | Лист с радио-строками и кнопкой «Скачать ZIP · {размер}» из `total_bytes` | | Объём заранее | S7 |

## 2. Действия клиента

| Действие | Что делает интерфейс | Решение и почему | Источник |
|---|---|---|---|
| Открыть сайт впервые | Показывает D01, ничего не создаёт | Архив и сессия создаются только после согласия и выбора файла: без согласия нельзя обрабатывать сведения о здоровье | S41 |
| Дать согласие | Активирует кнопку, подпись причины исчезает | Disabled всегда с причиной | S7 |
| Выбрать файл (кнопка или перетаскивание) | Проверяет тип и размер до загрузки, затем presigned POST | Ошибка размера до траты трафика | S45 |
| Перетащить не PDF | Сразу «Файл не добавлен: это не PDF» | Ранняя обратная связь | S7 |
| Ждать загрузку | Полоса процента, форма доступна для ввода | Параллельно с загрузкой человек заполняет поля | S6 |
| Получить AI-подсказку | Поля заполняются по одному, метка «подсказка», «Заполнить вручную» доступна сразу | Подсказка не блокирует; таймаут 10 с | S6 |
| Ввести название | Счётчик после 180 символов, ошибка после попытки сохранить | | S7 |
| Выбрать тип | Сегмент из 3 вариантов | 2 до 4 вариантов видны сразу | S8 |
| Ввести дату | Маска дд.мм.гггг, календарь по иконке, проверка существования даты и не в будущем | | S7 |
| Отметить «Дата не указана» | Поле даты блокируется, подсказка про фильтр по дате | Явное «неизвестно» вместо пустоты | S3 |
| Сохранить | Кнопка loading без смены ширины, затем тост и подсветка строки 1200 мс | Пользователь видит, куда встал документ | S6 |
| Нажать «Сохранить» дважды | Второй запрос с тем же `Idempotency-Key` | Нет дубля | S19 |
| Закрыть форму с данными | «Закрыть без сохранения?» | Защита ввода | S2 |
| Искать | Фильтр с 3 символов, задержка 250 мс, чип запроса, «N из M» | Видно, что список отфильтрован | S8 |
| Фильтровать по периоду | Выбор поля даты сегментом, период, подсказка про документы без даты | | S8 |
| Нажать «Показать его» | Список только документов без даты, чип «Без даты» | Путь к «потерянному» документу в один клик | S3 |
| Снять фильтр | Крестик на чипе или «Сбросить всё» | Отмена одним действием | S8 |
| Сортировать | Заголовок колонки с `aria-sort`, без даты всегда в конце | Предсказуемо | S9 |
| Открыть документ | Клик по всей строке или Enter | Цель нажатия вся строка | S10 |
| Читать PDF | Встроенный просмотрщик, «Открыть в новой вкладке», «Скачать» | Нативный поиск и печать браузера | S12 |
| Писать заметку | Автосохранение 800 мс, «Сохраняем… / Сохранено / Не сохранилось. Повторить» | Нет потери текста | S56 |
| Правка в двух вкладках | Сообщение о конфликте, текст сохранён в поле, «Обновить» | Не теряем ввод | S17 |
| Изменить название, тип, дату | «Изменить описание» открывает ту же форму | Одна форма для создания и правки | S1 |
| Удалить | Меню строки «Ещё» → модалка → тост | Опасное действие спрятано на шаг глубже и подтверждается | S2 |
| Экспортировать | Выбор объёма, размер заранее, потоковое скачивание | | S7 |
| Переключить тему | Иконка луны / солнца, выбор сохраняется | По умолчанию системная | S4 |
| Открыть на другом устройстве | Ввод ключа доступа, 6 групп по 4 символа | Ключ без регистрации | S51 |
| Выйти на этом устройстве | Сессия отзывается, cookie стирается | Общий компьютер | S28 |
| Удалить архив | Ввод слова «удалить», затем сообщение о сроке очистки 24 ч | Необратимо, двойная защита | S2, S48 |
| Потерять связь | Баннер, блокировка изменений с причиной | | S7 |
