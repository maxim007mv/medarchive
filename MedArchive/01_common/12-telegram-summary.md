**Медархив: решение тестового задания**

Личный архив медицинских PDF: загрузить, подписать (название, тип, дата документа), найти, отфильтровать по дате документа или загрузки, открыть, добавить заметку, удалить, выгрузить ZIP. Документ без даты не теряется: он помечен и показывается по ссылке из подсказки фильтра.

**Стек:** Next.js 15 + TypeScript + Tailwind 4 + Radix, FastAPI (Python 3.12), PostgreSQL 17, Yandex Object Storage + KMS, всё в Yandex Cloud ru-central1 (152-ФЗ).

**Что внутри пакета:**
• брендбук PDF на 33 страницы: палитра с контрастом, шрифт Medeo, компоненты и состояния, «правильно / неправильно», все экраны;
• путь пользователя по шагам, архитектура, API v1 (OpenAPI 3.1, 32 кода ошибок), схема БД с RLS и шифрованием, модель угроз и 152-ФЗ;
• 39 ADR с источниками, каталог паттернов, обоснование каждого экрана;
• ТЗ для AI-агентов: дизайн, фронт, бэк, БД, QA, DevOps; 78 тест-кейсов (46 P0);
• макеты в Figma: десктоп и мобильный, светлая и тёмная тема.

**Безопасность:** сессия в HttpOnly-cookie, ключ доступа вместо регистрации, шифрование полей и файлов ключом архива под KMS, изоляция архивов на уровне БД, удаление архива уничтожает ключ.
