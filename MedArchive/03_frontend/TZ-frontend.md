# ТЗ фронтенд: Медархив (Next.js 15)

Роль: фронтенд-разработчик или AI-агент. Входы: `02_design/brandbook.md`, `02_design/tokens.css`, `02_design/screens.md` + Figma, `01_common/04-customer-journey.md`, `01_common/openapi.yaml`. Выход: приложение `apps/web`, проходящее e2e-набор из `05_qa/test-cases.md`.

## 0. Правила работы
1. Тексты интерфейса копируются из `04-customer-journey.md` и `06-api-contract.md` дословно. Не придумывать формулировки.
2. Никаких цветов, отступов и радиусов вне токенов. Литерал `#...` в компоненте = замечание на ревью.
3. Все запросы к API только через сгенерированный клиент (`pnpm gen:api`).
4. Каждая задача закрывается тестом (unit или e2e), номер задачи в названии коммита: `FE-07: фильтр по датам`.

## 1. Структура

```
apps/web/
  app/
    layout.tsx               шрифт Medeo, тема, Providers, viewport-fit=cover
    page.tsx                 / : онбординг (0 документов) или список
    documents/[id]/page.tsx  просмотр документа
    settings/page.tsx        «Хранение и доступ»: ключ, удалить архив
  components/ui/             Button, IconButton, Input, DateInput, Textarea, SegmentedControl, RadioRow, Checkbox, Tag, Chip, Dialog, Sheet, Toast, Skeleton, Banner
  components/documents/      DocumentTable, DocumentCard, Toolbar, AppliedFilters, EmptyArchive, EmptySearch, UploadDialog, EditForm, NotePanel, DeleteDialog, ExportDialog, PdfViewer, AiSuggestBlock
  lib/api/                   сгенерированный клиент + обёртки TanStack Query
  lib/filters.ts             парсинг/сериализация фильтров в URL (nuqs)
  lib/format.ts              даты ru, размеры «79 КБ», имя по умолчанию из имени файла
  styles/tokens.css          копия 02_design/tokens.css
```

## 4. Мобильная адаптация (обязательные детали)
1. `viewport-fit=cover` в `layout.tsx` (`export const viewport`).
2. Закреплённая кнопка «Добавить PDF»: `padding-bottom: calc(16px + env(safe-area-inset-bottom))`, фон градиентом от прозрачного к `bg` уходит под край.
3. Нижние листы: `padding-bottom: calc(16px + env(safe-area-inset-bottom))`; никакая кнопка не касается нижнего края.
4. Цели нажатия главных действий 48 px, иконки-кнопки 40 px.

## 5. Сетка и отступы (как проверять на ревью)
Только 8/16/24/32/48 для раскладки и 2/4/6/10/12 внутри компонентов. Заголовок и текст 8, текст и кнопка 16, блоки 24 до 32. В Tailwind это `gap-2/4/6/8`, `p-4/6/8`. Значения `gap-[13px]` запрещены линтером (`eslint-plugin-tailwindcss` + собственное правило).

## 6. Производительность
JS первой загрузки < 180 КБ gzip; список рендерится сервером (RSC) с первыми 200 документами; виртуализация не нужна до 500 строк; изображения отсутствуют; шрифт: только 400/500/600 Sans и 400 Mono.

## 7. Доступность
`lang="ru"`; таблица семантическая; порядок табуляции: шапка → поиск → фильтры → таблица; `aria-live` для «Сохранено» и тостов; ошибки `role="alert"`; все иконки-кнопки с `aria-label`; фокус видимый 2 px `accent`; ручная проверка клавиатурой и VoiceOver/NVDA по чек-листу `05_qa/test-strategy.md`.
