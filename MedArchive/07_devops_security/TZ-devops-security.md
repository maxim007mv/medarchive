# ТЗ: DevOps и безопасность (роль: AI-агент DevOps / SecOps)

Цель: развернуть «Медархив» локально одной командой и онлайн в Yandex Cloud ru-central1 так, чтобы выполнялись 152-ФЗ (локализация, специальная категория ПДн) и меры из `01_common/08-security-privacy.md`.

## 1. Почему только Yandex Cloud ru-central1

Медицинские сведения это специальная категория ПДн (152-ФЗ ст. 10, S41). Запись, систематизация, накопление и хранение ПДн граждан РФ выполняются в базах данных на территории РФ (ст. 18 ч. 5, S42). Поэтому все хранилища ПДн (PostgreSQL, Object Storage, Redis, логи, бэкапы) находятся в ru-central1. Ранее рассмотренные Vercel, Fly.io, Neon, Supabase отброшены для онлайн-среды с реальными данными: их регионы вне РФ. Для локального запуска внешние сервисы не нужны.

## 2. Целевая инфраструктура

| Компонент | Сервис | Параметры | Почему |
|---|---|---|---|
| Веб (Next.js) и API (FastAPI) | Yandex Serverless Containers или Compute Cloud + Docker | 2 инстанса API, 1 vCPU, 1 ГБ | Без Kubernetes: два контейнера проще эксплуатировать |
| БД | Managed Service for PostgreSQL 17, 2 хоста в разных зонах | Ежедневная копия + PITR 7 дней (S46) | Отказоустойчивость и восстановление на момент времени |
| Пул | PgBouncer в режиме transaction (встроенный в Managed PostgreSQL) | `app.workspace_id` через `set_config(..., true)` | Безопасно для RLS в пуле (07-database) |
| Файлы | Object Storage: бакеты `ma-quarantine` (жизненный цикл 1 день) и `ma-docs` (только шифртекст), версионирование выключено, публичный доступ запрещён | Presigned POST с `content-length-range` (S45) | Файл не проходит через API |
| Ключи | Yandex KMS: симметричный KEK AES-256, ротация раз в год; DEK на пространство, обёрнут KEK (envelope, S44) | Права `kms.keys.encrypterDecrypter` только сервисному аккаунту API | Компрометация БД или бэкапа без KMS не раскрывает данные |
| Очередь и лимиты | Managed Redis | Только счётчики и очередь AI, без ПДн | |
| Секреты | Lockbox | Подключение к БД, ключ HMAC курсоров | Нет секретов в образах и переменных CI |
| TLS | Certificate Manager + ALB, TLS 1.2+ , HSTS `max-age=31536000; includeSubDomains` | | |
| Логи | Cloud Logging, хранение 30 дней | Без ПДн: только `request_id`, маршрут, код, длительность | ASVS V16 (S49) |

## 3. Задачи

| ID | Задача | Критерий готовности |
|---|---|---|
| OPS-01 | `docker compose up` поднимает web 3000, api 8000, postgres 17, minio, redis; `make seed` загружает 6 фикстур | С нуля до работающего сценария меньше 5 минут по README |
| OPS-02 | Terraform для раздела 2 | `terraform plan` без ручных шагов, состояние в Object Storage с блокировкой |
| OPS-03 | CI GitHub Actions: lint, typecheck, unit, интеграционные (Testcontainers), E2E, schemathesis, сборка образов | Время PR меньше 12 минут |
| OPS-04 | Безопасность цепочки поставки: Dependabot, `pip-audit`, `npm audit --omit=dev`, Trivy по образам, gitleaks | Critical блокирует merge |
| OPS-05 | Образы: distroless или slim, пользователь не root, файловая система только чтение, `HEALTHCHECK` | Trivy без high в базовом образе |
| OPS-06 | Заголовки на ALB / Next.js: CSP `default-src 'self'; frame-ancestors 'none'; object-src 'none'`, `Referrer-Policy: no-referrer`, `Permissions-Policy` пустая для камеры и геолокации | Проверка securityheaders A |
| OPS-07 | Миграции отдельным шагом деплоя от роли `ma_owner`, приложение работает от `ma_app` | Приложение не может менять схему |
| OPS-08 | Алёрты: 5xx больше 1% за 5 мин, p95 списка больше 300 мс, ошибки KMS, заполнение очереди AI больше 80% | Тестовый алёрт доходит |
| OPS-09 | Восстановление: квартальный тест PITR на отдельный кластер | Протокол: RTO меньше 1 ч, RPO меньше 5 мин |
| OPS-10 | Модель угроз и тесты из `08-security-privacy.md` в CI (TC-090 до TC-098) | Зелёные |
| OPS-11 | 152-ФЗ: политика обработки ПДн опубликована, версия в `consents.policy_version`; уведомление Роскомнадзора об обработке ПДн подаётся до начала обработки (152-ФЗ ст. 22 ч. 1, S57) с составом по ч. 3 и 3.1: цель, категория «специальные: состояние здоровья», меры и шифровальные средства (Tink, Yandex KMS), отсутствие трансграничной передачи, место нахождения БД (Yandex Cloud ru-central1) | Ссылка на политику в D01, в журнале согласий версия совпадает |
| OPS-12 | Удаление: задача очистки (DB-09) и криптоудаление DEK по запросу пользователя | Тест: после удаления архива объект в бакете не расшифровывается |

## 4. Бюджеты производительности (p95, онлайн)

| Операция | Бюджет | Как достигается |
|---|---|---|
| `GET /documents` (50 строк) | 150 мс | Индекс keyset, расшифровка 50 названий AES-GCM меньше 1 мс, ключи пространства расшифровываются KEK один раз на запрос, без кэша (ADR-041) |
| `GET /documents?q=` | 250 мс | Слепой триграммный индекс GIN |
| `PATCH` заметки | 150 мс | Одна строка, `If-Match` |
| `POST /documents` (1 МБ PDF) | 1,5 с | Проверка pypdf + потоковое шифрование + копирование в бакет |
| Первая отрисовка списка (LCP) | 2,0 с на 4G | SSR каркаса, шрифт Medeo через `next/font/local` без внешних запросов (S54) |

## 5. Чего не делать

Не включать публичные ссылки на объекты; не выносить логи, метрики с ПДн или бэкапы за пределы РФ; не использовать внешние CDN для шрифтов и скриптов; не давать CI права на KMS расшифровку.
