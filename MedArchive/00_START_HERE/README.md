# Медархив: пакет решения тестового задания

Личный архив медицинских PDF. Человек загружает документ, подписывает его (название, тип, дата документа), находит по названию, фильтрует по дате документа или дате загрузки, открывает, пишет заметку, удаляет и выгружает ZIP. Дата загрузки фиксируется автоматически отдельно от даты документа. Документ без даты не теряется: он помечен «Не указана», стоит в конце списка и показывается по ссылке из подсказки фильтра.

**Стек одной строкой:** Next.js 15 + TypeScript + Tailwind 4 + Radix/shadcn, FastAPI (Python 3.12) + SQLAlchemy 2, PostgreSQL 17 (проверено на 18), Yandex Object Storage + KMS, всё в Yandex Cloud ru-central1 (152-ФЗ ст. 18 ч. 5).

**Шрифт:** Medeo Sans и Medeo Mono 1.1.0 (студия DNF, лицензия SIL OFL 1.1, npm `medeo-font`): полная кириллица, вариативный вес, моно-начертание для дат. Встроен в PDF брендбука.

**Макеты Figma:** https://www.figma.com/design/wcz0Kh4DkoVRqGBEvp4uT2 (десктоп 1440 и мобильный 390, светлая и тёмная тема). Структура файла: страница «Десктоп» с секциями «Светлая тема · D01-D16» и «Тёмная тема · ключевые экраны», страница «Мобайл» с секциями «Светлая тема · M01-M08» и «Тёмная тема · ключевые экраны». Слои экранов названы по номерам из `02_design/screens.md`. Бесплатный тариф Figma ограничивает файл тремя страницами, поэтому разбиение по теме сделано секциями, а не отдельными страницами. Третья страница «Служебная · дубликат» содержит повторный захват D09-D16 и может быть удалена.

## Принципы пакета

Каждое решение записано как «что выбрано, где, что отброшено, почему, источник». Источники только прочитанные (таблица `01_common/02-research-sources.md`). Нормы 152-ФЗ взяты из текстов статей на КонсультантПлюс, Гаранте, сайте Минтруда и bazanpa.ru; страницы КонсультантПлюс отрисовываются скриптом, поэтому текст сверялся по выдаче поиска и зеркалам.
